# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-04
### Added
- Model-agnostic Universal AI Workspace core engine.
- Providers: NVIDIA NIM, OpenRouter, Ollama, and OpenAI-compatible endpoints.
- Capability registry and intelligent model router with error fallback.
- BYOK AES-256-GCM encrypted local vault with zero plain-text leaks.
- Universal Task Orchestrator with automatic task classification and 8-stage execution pipeline.
- Specialized Agents: Coding, Research, Data Analysis, SQL, Automation DAG, Creative Media, Document, General.
- 30+ schema-validated tools for files, terminal, git, SQL, web scraping, and media.
- Security layers: PathShield (path traversal), CommandShield (destructive shell prevention), PromptDefense (untrusted data boundaries).
- Vanilla CSS design system with Dark/Light modes, resizable split-pane layout, execution timeline, and collapsible bottom panel.
- Electron container for Windows desktop app packaging (`.exe` NSIS installer & portable executable).
- Multi-platform GitHub Actions CI and release packaging workflows.
