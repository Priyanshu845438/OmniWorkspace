# Phase 3 Backlog & Future Architectural Roadmap

This backlog catalogs feature expansions, enterprise capabilities, and extended research modules strictly deferred from Phase 2. As per the OmniWorkspace architecture guidelines, Phase 2 strictly focused on core integration, security boundaries, and zero-gap correctness.

---

## 1. Advanced Semantic Retrieval & Vector Indexing
- **Vector Embedding Store**: Local vector storage (e.g. SQLite-VSS, DuckDB, or embedded Qdrant) for semantic code search.
- **Hierarchical Chunking**: AST-aware chunking preserving scope boundaries across TypeScript, Python, Rust, and Go.
- **Hybrid Search**: Reciprocal Rank Fusion (RRF) combining BM25 keyword matching with dense vector embeddings.

## 2. Multi-Agent Autonomous Swarm Coordination
- **Hierarchical Subagent Delegation**: Dynamic parent-child agent topologies where a principal agent can spin up specialized ephemeral agents.
- **Inter-Agent Message Bus**: Formal RPC protocol allowing the Coding Agent and Research Agent to exchange structured deliverables.
- **Consensus & Voting Engines**: Multi-model debate protocols (e.g. Claude 3.5 Sonnet reviewing code generated by DeepSeek-R1).

## 3. Natural Language Workflow Generation & Visual Canvas
- **Text-to-DAG Synthesis**: Converting natural language automation goals into verified DAG execution specifications automatically.
- **Drag-and-Drop Node Visualizer**: Interactive canvas (e.g. React Flow or xyflow) with visual connection dragging and real-time step debugger.
- **Webhook & Cron Triggers**: Live background cron scheduling and incoming webhook HTTP receivers.

## 4. Model Benchmarking & Eval Arena
- **Automated Code Eval**: Running standard HumanEval / MBPP benchmark suites locally against configured models.
- **Latency & Token Cost Tracker**: Real-time token usage telemetry, running cost calculation per query, and provider comparison graphs.
- **Blind Elo Rating Engine**: Double-blind prompt comparison with human feedback voting for model evaluation.

## 5. Community Plugin Marketplace & Sandboxed WASM Runtimes
- **WASM Plugin Sandboxing**: Executing untrusted community plugin code inside WebAssembly / QuickJS sandboxes with strict syscall filtering.
- **Remote Plugin Registry**: One-click installation of community verified tools and integrations from GitHub releases.
- **Language Server Protocol (LSP) Bridge**: Direct stdio integration with `tsserver`, `pyright`, `gopls`, and `rust-analyzer`.

## 6. Enterprise Collaboration & Extended Security
- **Multi-Seat Workspaces**: Team-shared encrypted project vaults and role-based access control (RBAC).
- **Audit Log Forwarders**: Syslog / Splunk / Datadog streaming for enterprise compliance and audit trails.
- **Air-Gapped Installation Bundles**: Fully self-contained offline installer packaging bundled local LLM weights and dependencies.
